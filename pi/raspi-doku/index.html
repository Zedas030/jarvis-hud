Architektur & Datenflüsse

Wie die Dienste zusammenarbeiten. Durchgezogene Kästen laufen auf dem Raspi, gestrichelte sind externe Geräte oder Clouds.

Energie / MQTT Prometheus fragt ab (Pfeil zeigt zum Ziel) DNS / Erreichbarkeit Geräte-Integrationen

Der Energie-Kreislauf in Worten

  1. noah-mqtt holt alle 60 s Daten des Growatt-NOAH-Speichers aus der Growatt-Cloud und veröffentlicht sie auf Mosquitto.
  2. Home Assistant liest das per MQTT- und Growatt-Integration. Die Automation „StromAutomatisierung“ berechnet einen Sollwert und setzt die NOAH-Ausgangsleistung (Nulleinspeisung).
  3. Die Automation „Hausverbrauch → MQTT Smart Meter“ schreibt den aktuellen Hausverbrauch auf das Topic home/hausverbrauch (JSON, Feld power).
  4. uni-meter liest dieses Topic und gibt sich im Netz als Eco-Tracker-Smart-Meter aus (UDP 1010, Poll 3 s, einphasig), damit der Speicher den Verbrauch „sieht“.
  5. Zu jeder Automation gibt es eine Watchdog-Automation, die prüft, ob sie noch arbeitet.

Ausnahmen

Akzeptierte Befunde zählen nicht in die Bewertung und kommen nach Ablauf zurück.
Zeitleiste
Ereignisse neuer/behobener Befund, Port auf/zu, neues Gerät (nicht im Inventar), Ausnahme gesetzt/beendet – 120 Tage in state.json, 90 Tage auf der Website; auch je Gerät in der Netzwerkprüfung und auf der Geräteseite.

Leitet eine Oberfläche HTTP selbst auf HTTPS um (per 30x oder JavaScript, z. B. DSM :5000 → :5001), gilt „auch per HTTP erreichbar“ nicht als Befund. Die DNS-Reserve-Adresse 10.0.0.250 (keepalived) zählt nicht als eigenes Gerät; unter „Was geprüft wurde“ steht, ob sie gerade auf dem Pi oder auf der NAS liegt.

🔀 Anfrageweg – vom Wort zur Antwort

  1. Hören: Der Browser erkennt Sprechpausen (VAD) und schickt den Clip an /api/listen. Whisper (large-v3-turbo, GPU) macht daraus Text.   2. Router: router.route probiert die 25 lokalen Handler der Reihe nach (Not-Aus, Persönlichkeit, Kontext, Prüfungen, Fenster, Routinen, Timer, Listen, Aussprache, Bericht, PC, Fahrzeit, Pakete, Drucker, Hauszustand, Klima, Haus, Musik, Uhrzeit, Datum, Sonne, Wetter, Solar, NAS, Pi). Messung: über 25× weniger Tokens als ein Standard-Aufruf.
  6. Werkzeuge: Jeder Aufruf läuft durch jarvis_mcp.handle_call: Aktionsklasse, Sperrliste, Taint-Prüfung, Audit, Größenlimit (2.500 Zeichen), Markierung fremder Daten. CONFIRM-Werkzeuge zeigen eine Karte im HUD.
  7. Ausfall: Ist Claude blockiert oder bricht ab, bevor ein Wort gesagt ist, übernimmt fallback_llm.run mit denselben Werkzeugen.
  8. Sprechen: Die Antwort kommt als NDJSON-Stream Satz für Satz; jeder Satz geht an /api/speak und die Stimmen-Kette. Gesprochene Fragen bekommen kurze Antworten, getippte ausführliche (vorgelesen wird nur der erste Absatz).
  9. Nachher: Verbrauch in logs/usage.jsonl, Gespräch im Tagesprotokoll (ohne Arbeitsthemen), 30 min später bewertet die Lernschleife das Gespräch.

🛡️ Sicherheitsmodell

Das Modell ist nie die Sicherheitsgrenze. Rechte stehen im Code (jarvis_mcp.handle_call, policy.py, HUD-Karte); der Prompt erklärt sie nur.

RegelUmsetzung
AktionsklassenREAD (frei) · LIMITED_WRITE (kleine, umkehrbare Änderung: Lampe, Listeneintrag, Notiz, Timer, Fenster) · CONFIRM (Außenwirkung, Löschen, Kalender, Mail-Entwurf, Skripte, Regeln, Updates) · BLOCKED. Jedes Werkzeug muss eine Klasse haben, sonst schlägt tests/test_policy.py fehl.
Fremde DatenMail, Web, Kalender, Dateien, Zwischenablage, Bildschirm, Tagesvorbereitung stehen zwischen «FREMDE DATEN»-Markern (falsche End-Marker werden entschärft). Danach braucht jede Änderung im selben Auftrag eine Karte („Taint“). Ein MCP-Prozess pro Anfrage.
KartenZeigen Begründung, Aktion, Ziel, Details, Folgen. Nur Tippen oder „bestätigt“ zählt – „ja“/„okay“ nicht. Eine Karte gilt für genau einen Aufruf. Ohne Antwort nach 75 s (JARVIS_PERM_TIMEOUT) = nein. Ohne offenes HUD = nein.
HintergrundjobsÄndern nie selbst etwas, sie legen Vorschläge an (proposals.py), die per Karte angenommen werden. Einzige vom Nutzer gewählte Ausnahme: Buchungen vertrauter Absender (PC CADDIE, golftimer, Golf House) und erwartete Lieferungen werden direkt in den Kalender eingetragen, angesagt und sind per „Termine rückgängig“ entfernbar.
Kalender zuerstVor jedem Eintrag liest der Code den Tag (icloud_calendar.check): ähnlicher Titel am selben Tag → kein Vorschlag; Überschneidung → steht auf der Karte.
DatenschutzArbeitsthemen werden nirgends gespeichert (privacy.py, JARVIS_WORK_TERMS). Gemini (Gratis-Tarif, darf trainieren) sieht nie Mail, Kalender, Gesundheit, Briefing. Bildschirm-OCR lokal; gesperrt bei Passwortmanager, Banking, Messenger. Dateien nur unter Desktop, Dokumente, Downloads. Mails nur der letzten 24 h.
Not-Aus„Jarvis, stopp alles“ / „Not-Aus“ (lokal): Karten abgelehnt, Claude gestoppt, Meldungen, Jobs und Geplantes pausieren 2 h (JARVIS_PAUSE_HOURS). Wecker klingeln weiter. „weitermachen“ hebt auf.
